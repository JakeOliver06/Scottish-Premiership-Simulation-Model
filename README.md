# Scottish Premiership Season Simulation

Poisson goal model and Monte Carlo season simulator built on Scottish 
Premiership 2023/24 match data.

## Overview
- Estimates team attack and defence strengths from historical results
- Simulates 10,000 full seasons including the SPFL split structure
- Produces title, European qualification and relegation probabilities
- Validated against actual 2023/24 final standings

## Libraries
pandas, numpy, matplotlib, seaborn, scipy

## Data
football-data.co.uk
